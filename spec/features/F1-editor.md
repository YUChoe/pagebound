# F1. 쓰기 개선 (R1)

관련: [F2 첨부](F2-attachments.md), [F3 위키 링크](F3-tree-links.md), 단계 [M3](../phases/M3-write.md), [M7](../phases/M7-history-p1.md)

## 1. 에디터 화면

- 좌: CodeMirror 6 소스 / 우: 미리보기. 스크롤 동기화. 미리보기 숨김 토글
- 상단: 제목, 분류(태그) 입력, 편집 요약, 저장/취소
- 툴바: 헤딩, 굵게, 코드, 코드블록([F9](F9-code-blocks.md) 6절), 링크, 위키 링크, 표, 체크리스트, 콜아웃, 각주, 첨부
- 단축키: `Ctrl+S` 저장, `Ctrl+K` 링크, `Ctrl+Shift+V` 서식 없이 붙여넣기
- `[[` 입력 시 문서 경로 자동완성
- 섹션 편집 진입(`/edit/{path}?section=n`) 시 해당 섹션만 로드, 저장 시 서버에서 병합
- 우측 사이드 패널: 첨부 목록 ([F2](F2-attachments.md) 3절)

## 2. 붙여넣기 / 드래그 앤 드롭

| 클립보드 내용 | 동작 | 우선순위 |
|--------------|------|---------|
| 이미지 바이너리 (스크린샷) | 업로드 → 커서 위치에 `![](/p/{pageId}/files/{name})` 삽입 | P0 |
| 파일 (탐색기 복사, 드래그) | 이미지면 `![]()`, 그 외 `[파일명](...)`. 다중 파일 | P0 |
| 일반 텍스트 | 그대로 | P0 |
| 엑셀/스프레드시트 셀 (TSV) | 마크다운 표로 변환 | P1 |
| HTML (웹, Word, Confluence) | turndown 변환. 포함 이미지(`data:`/외부 URL)는 다운로드 후 첨부 업로드 | P1 |
| 텍스트 선택 상태에서 URL | `[선택텍스트](URL)` | P1 |
| URL (선택 없음) | 그대로 삽입. 미리보기 카드/칩 렌더는 [F10](F10-link-preview.md) | P0 |

규칙:
1. 업로드 중 플레이스홀더 삽입, 완료 시 치환, 실패 시 제거 + 토스트
2. 파일명 없는 이미지: `paste-YYYYMMDD-HHmmss.png`
3. 같은 페이지에 동일 파일명 존재 시 `name-1.ext` 자동 부여 (서버에서 결정, 최종 파일명 응답)
4. 제한: 파일당 50MB, 1회 10개 (설정값)
5. 미저장 신규 문서에서 붙여넣기: 첫 업로드 시점에 `is_draft=1` 문서를 생성해 page_id 확보. 초안은 트리/검색 미표시, 저장 시 `is_draft=0`, 24시간 방치 초안은 첨부와 함께 정리 (Q4 확정)

## 3. 저장

- 낙관적 잠금: 요청에 `version` 포함, 불일치 시 409 + 현재 내용과 diff 표시 → 덮어쓰기 / 내 내용 복사 후 새로고침 선택
- 로컬 자동 임시저장: 5초 디바운스로 localStorage, 재진입 시 복원 제안
- 저장 트랜잭션: `pages` 갱신 → `page_revisions` 추가(`source='web'`) → `page_links` 재계산 → FTS 트리거

## 4. API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| POST | `/api/v1/pages` | 생성 (`parentId`, `title`, `slug?`, `content`, `tags[]`, `draft?`) |
| GET | `/api/v1/pages/{id}/source?section=n` | 편집용 원문 (섹션 지정 가능) |
| PUT | `/api/v1/pages/{id}` | 수정 (`version`, `title`, `content`, `tags[]`, `summary`, `section?`) |

## 5. 완료 기준

| 항목 | 기준 |
|------|------|
| 스크린샷 붙여넣기 | Ctrl+V → 업로드 → 본문 삽입 → 저장 → 문서 화면 표시 |
| 파일 다중 드롭 | 3개 동시 드롭 시 3개 링크 삽입 |
| 동일 파일명 | 두 번째 업로드가 `-1` 접미사로 저장 |
| 동시 편집 | 다른 세션 저장 후 저장 시 409 + diff |
| 섹션 편집 | 섹션 2.1만 수정 후 다른 섹션 원문 불변 |
