## 2. 진입점

| 요소 | 사양 | 우선순위 |
|------|------|---------|
| 헤더 검색창 | 모든 화면 상단. 단축키 `/` 로 포커스 (입력 요소에 포커스가 있으면 무시) | P0 |
| 제목 자동완성 | 입력 중 200ms 디바운스로 제목·경로 부분 일치 상위 8건 드롭다운. ↑↓ 선택, Enter 이동 | P0 |
| 바로가기 | 검색어가 문서 경로 또는 제목과 정확히 일치하면 드롭다운 첫 줄에 "→ 바로 이동" (namu.wiki 방식). 그 외 Enter는 결과 화면 | P0 |
| 결과 화면 | `/search?q=...&tags=...&path=...&sort=...&page=...` (URL 공유 가능) | P0 |
| 최근 검색어 | 검색창 포커스 시 최근 10개 (localStorage) | P2 |

## 3. 검색 대상

| 대상 | 사양 | 우선순위 |
|------|------|---------|
| 제목·경로 | 일치 시 가중치 높음 (6절) | P0 |
| 본문 원문 | 마크다운 원문 전체 (코드블록 포함) | P0 |
| 범위 지정 `in:title` / `in:code` | 제목만 / 코드블록 안만 | P1 |
| 첨부 파일명 | `in:file` 또는 기본 검색에 포함, 결과에 "첨부" 배지 | P1 |
| 첨부 텍스트 내용 | txt·log·conf·sql·md 등 텍스트 계열 1MB 이하 | P2 |

제외: 초안(`is_draft=1`), 휴지통(`deleted_at`) 문서, 과거 리비전.

## 4. 질의 문법

| 문법 | 의미 | 예 | 우선순위 |
|------|------|----|---------|
| `a b` | 모든 단어 포함 (AND) | `altibase 라이선스` | P0 |
| `"a b"` | 구문 그대로 포함 | `"Connection refused"` | P0 |
| `-a` | 제외 | `nginx -apache` | P0 |
| `tag:x` | 태그 필터 (여러 개면 AND, 태그 화면 F4와 동일) | `tag:nems tag:altibase` | P0 |
| `path:x` | 경로 접두 필터 (하위 트리 안에서만) | `path:nems/프로젝트` | P0 |
| `in:title` `in:code` `in:file` | 범위 지정 | `in:code max_connections` | P1 |
| `author:x` | 최종 수정자 | `author:홍길동` | P2 |

- 대소문자 무시. 따옴표 짝이 안 맞으면 따옴표를 일반 문자로 취급
- 필터만 있고 검색어가 없으면(`tag:nems`) 해당 조건 문서를 최근 수정순으로 나열
- 결과 화면의 필터 UI는 같은 문법을 URL 파라미터(`tags`, `path`)로 표현

| 페이지 | 20건 단위, 총 건수 표시 | P0 |
| 결과 없음 | 철자 확인 안내 + 편집 권한자에게 "‘검색어’ 문서 만들기" (레드 링크와 같은 동작) | P0 |
| 모바일 | 패싯은 결과 위 접이식 패널 | P0 |

## 6. 순위 규칙 (관련도)

1. 제목 완전 일치
2. 제목 접두 일치
3. 제목 부분 일치 / 경로 일치
4. 본문 FTS bm25 점수 (제목 열 가중치 10, 본문 1)
5. 동점이면 최근 수정순

## 7. 한국어·짧은 검색어 처리

| 검색어 길이 | 처리 |
|------------|------|
| 3자 이상 | FTS5 trigram `MATCH` (구문은 `"..."` 그대로 전달) |
| 1~2자 (`통계`, `ha`) | `LIKE '%…%'` 조건으로 처리. 문서 수가 적어 허용 (2,000문서 기준 성능 목표 8절) |
| 혼합 (`ha 구성`) | 단어별로 위 규칙을 적용해 AND 결합 |

- 특수 문자(`:`, `/`, `.`, `-` 포함 단어. 예: `nes-api`, `/etc/hosts`)는 FTS 연산자로 해석되지 않도록 단어 전체를 구문으로 감싸 전달

## 8. 색인

| 단계 | 구조 | 우선순위 |
|------|------|---------|
| 현재 (M1 구현) | `pages_fts(title, content)` external content + 트리거 동기화 | P0 그대로 사용 |
| 확장 | Flyway `V2`: `search_index(page_id, title, path, body, code, files)` FTS5 trigram, 애플리케이션이 저장 시 갱신 (본문/코드 분리는 flexmark 필요하므로 트리거 불가). `pages_fts`와 트리거 제거 | P1 (`in:code`, `in:file` 도입 시) |

- 전체 재색인: 마이그레이터 마지막 단계와 관리자 화면 "검색 색인 재구축" 버튼 (P1, [F12](F12-admin.md) 11절)

## 9. API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/v1/search?q=&tags=&path=&sort=relevance\|updated&page=1&size=20` | 결과 `{ total, items[], facets }` |
| GET | `/api/v1/search/suggest?q=` | 자동완성 `[{ path, title, exact }]` 최대 8건 |

결과 항목:

```json
{
  "path": "nems/Altibase/license",
  "title": "Altibase 라이선스 갱신",
  "breadcrumbs": [{ "path": "nems", "title": "nems" }],
  "tags": ["altibase"],
  "updatedAt": "2025-08-27T06:37:00Z",
  "updatedBy": "홍길동",
  "snippets": [{ "text": "… 라이선스 만료 시 \u0002altibase\u0003 서버가 …", "inCode": false }],
  "section": { "index": 3, "number": "2.1.", "title": "라이선스 발급" }
}
```

- 스니펫 강조는 HTML이 아닌 표식 문자(`\u0002` 시작, `\u0003` 끝)로 전달. 클라이언트가 텍스트를 이스케이프한 뒤 `<mark>`로 바꾼다 (XSS 방지)
- 권한: 조회 API와 동일 (익명 읽기 설정을 따름)

## 10. MCP 연동

- `search_pages` 입력을 `query`(4절 문법 그대로), `tags[]?`, `path?`, `limit?=10`으로 맞추고, 반환에 스니펫·섹션 번호를 포함 ([F6](F6-mcp-api.md) 3.1)
- 에이전트는 반환된 섹션 번호로 `get_page(section=…)`를 바로 호출할 수 있다

## 12. 완료 기준

| 항목 | 기준 |
|------|------|
| 한국어 | `통계`(2자), `파티션`(3자) 모두 결과 반환 |
| 코드 문자열 | 코드블록 안에만 있는 문자열(예: 설정 키) 검색 시 해당 문서 반환, 스니펫이 고정폭 표시 |
| 구문·제외 | `"…"` 구문 일치, `-word` 제외가 적용됨 |
| 필터 | `tag:` AND, `path:` 접두 필터 결과가 정확함 |
| 바로가기 | 문서 제목 그대로 입력 시 자동완성 첫 줄이 바로가기 |
| 순위 | 제목 일치 문서가 본문만 일치하는 문서보다 위 |
| 제외 대상 | 초안·휴지통 문서가 결과에 없음 |
| 특수 문자 | `nes-api`, `/etc/hosts` 검색 시 FTS 구문 오류 없이 결과 반환 |
| 성능 | 11절 기준 충족 |
