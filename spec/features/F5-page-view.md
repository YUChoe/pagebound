## 1. 레이아웃

```
┌────────────────────────────────────────────────────────────────────┐
│ 로고 │ 최근 변경 │ 랜덤 │            [검색 ─────── 🔍 →] │ 사용자   │
├──────────┬──────────────────────────────────────────┬──────────────┤
│ 트리     │ ┌ 문서 카드 ─────────────────────────────┐ │ 최근 변경    │
│ (접기)   │ │ 제목                [편집][역사][⋮]    │ │ 문서A  2분 전│
│          │ │ 최근 수정 시각 · 수정자                │ │ 문서B  1시간 │
│          │ │ 상위 문서: nems › 고도화               │ │ ...          │
│          │ │ ┌ 분류: nems │ 통계 │ altibase ──────┐ │ │              │
│          │ │ ┌ 목차 ─────────── ∨ ┐               │ │              │
│          │ │ │ 1. 개요            │               │ │              │
│          │ │ │ 2. 설정            │               │ │              │
│          │ │ │   2.1. 설정파일    │               │ │              │
│          │ │ └────────────────────┘               │ │              │
│          │ │ ∨ 1. 개요                     [편집]  │ │              │
│          │ │ ─────────────────────────────────────  │ │         [≡] │
│          │ │ 본문 ...                               │ │         [↑] │
│          │ │ 각주 / 첨부 파일 / 하위 문서           │ │         [↓] │
│          │ └────────────────────────────────────────┘ │              │
└──────────┴──────────────────────────────────────────┴──────────────┘
```

- 1280px 미만: 우측 최근 변경 숨김. 1024px 미만: 트리 오버레이
- 넓은 보기 토글: 본문 폭 제한 해제 (표가 많은 문서용), 문서별 기억
- `⋮` 메뉴: 역링크, 원문(.md), 영구 링크 복사, 이동, 휴지통

## 2. namu.wiki에서 가져오는 요소

| 요소 | 사양 | 우선순위 |
|------|------|---------|
| 분류 바 | 제목 아래 태그 표시, 클릭 시 태그 목록 | P0 |
| 인라인 목차 박스 | 본문 시작부, 헤딩 번호 표시, 접기 가능 | P0 |
| 헤딩 자동 번호 | `1.`, `2.1.` 형식. 문서 내 최상위 헤딩 레벨부터 번호 시작. 사용자 설정으로 끄기 가능 | P0 |
| 섹션 접기 | 헤딩 좌측 ∨ 클릭 시 섹션 접힘 | P0 |
| 섹션 편집 | 헤딩 우측 `[편집]` → 해당 섹션만 편집 (EDITOR 이상에게만 표시) | P0 |
| 레드 링크 | 없는 문서 링크는 빨간색 | P0 |
| 상위 문서 표시 | 제목 아래 breadcrumb | P0 |
| 최근 변경 | 우측 사이드바 10건 + `/recent` 전체 목록 (편집자, source, 요약, ±bytes) | P0 |
| 플로팅 버튼 | 목차 열기, 맨 위, 맨 아래 | P1 |
| 각주 | 본문 `[1]` hover 시 툴팁, 하단 각주 목록 | P1 |
| 검색 바로가기 | [F11](F11-search.md) 2절로 이관 (P0) | - |
| 역링크 | `⋮` 메뉴에서 참조 문서 목록 | P1 |
| 랜덤 문서 | 헤더 버튼 | P2 |
| 즐겨찾기(☆) | 개인 즐겨찾기 목록 | P2 |

제외: 토론, 실시간 검색어, 광고, 문서별 ACL, 틀(template)/include.

## 3. 본문 스타일

| 색 | 흰 배경 문서 카드 + 연회색 페이지 배경, 상단 바 단색 1개 | P0 |

| 표 | 가로 스크롤 컨테이너, 헤더 배경, 셀 테두리 | P0 |
| 이미지 | `max-width:100%`, lazy load, 클릭 확대 | P0 |
| 콜아웃 | `> [!INFO]` `> [!WARNING]` `> [!TIP]` `> [!DANGER]` (좌측 색 띠) | P0 |
| `<details>` | 테두리 박스 + 접힘 아이콘 | P0 |
| mermaid | 뷰포트 진입 시 렌더 | P0 |
| 외부 링크 | GitLab 이슈/MR 등 미리보기 카드·칩 ([F10](F10-link-preview.md)) | P0 |
| draw.io 다이어그램 | 마이그레이션 시 SVG 첨부로 전환되어 이미지로 표시 ([F8](F8-migration.md)) | P0 |
| 테마 | 라이트/다크 | P1 |
| 인쇄 | 트리/사이드바/버튼 숨김 | P1 |

## 4. 성능

- 최대 문서 `nems/고도화/NES-HISTORY` (본문 396KB) 렌더 완료 1초 이내
- 트리 API 200ms 이내 (전체 약 200노드)

## 5. API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/v1/pages/by-path?path=` | [F3](F3-tree-links.md) 7절 |
| GET | `/api/v1/recent?limit=&since=` | 최근 변경 |
| GET | `/w/{path}.md` | 원문 |
