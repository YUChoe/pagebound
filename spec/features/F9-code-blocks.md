## 2. 정보 문자열(info string) 문법

````
```java title="UserService.java" collapsed {3,5-7} start=120
...
```
````

| 속성 | 의미 | 우선순위 |
|------|------|---------|
| 첫 토큰 | 언어. 단, 첫 토큰이 속성 형식(`title=`, `collapsed`, `nolinenums`, `{…}`, `start=`)이면 언어 미지정 (예: ```` ```title="/etc/hosts" collapsed ````, M1 마이그레이션 산출 형식) | P0 |
| `title="..."` | 헤더에 파일명/제목 표시 | P0 |
| `collapsed` | 기본 접힘. 문서에 저장되므로 모든 사용자에게 적용 | P0 |
| `nolinenums` | 줄 번호 숨김 | P0 |
| `{3,5-7}` | 줄 강조 | P1 |
| `start=120` | 시작 줄 번호 (로그 발췌용) | P1 |

- GitHub 등 다른 렌더러는 첫 토큰 이후를 무시하므로 원문 이식성 유지
- 서버(flexmark)는 info string을 그대로 보존. MCP `get_page`는 원문을 반환하므로 속성 유지

## 3. 코드 보기

### 3.1 헤더 바

```
┌──────────────────────────────────────────────────────────────────┐
│ ∨  java · UserService.java · 142줄       [줄바꿈][복사][⤢][⋮]   │
├──────────────────────────────────────────────────────────────────┤
│  1 │ public class UserService {                                  │
│  2 │   ...                                                       │
└──────────────────────────────────────────────────────────────────┘
```

| 요소 | 사양 | 우선순위 |
|------|------|---------|
| 접기 토글 ∨ | 4절 | P0 |
| 언어 · title · 줄 수 | 언어 미지정 시 자동 감지 결과를 흐리게 표시 | P0 |
| 줄 번호 | 기본 표시, 선택·복사 대상에서 제외 | P0 |
| 복사 | 줄 번호 제외 원문 복사, 완료 표시 | P0 |
| 줄바꿈 토글 | 사용자 전역 설정으로 기억 (localStorage) | P0 |
| 전체화면 ⤢ | 모달, 화면 폭 전체, 가로 스크롤, Esc 닫기 | P1 |
| `⋮` 메뉴 | 원문 보기(plain text 모달), 파일로 다운로드(title 또는 `snippet.{ext}`), 기본 접힘 저장/해제(편집 권한자) | P1 |
| 줄 앵커 | 줄 번호 클릭 시 `#code-{n}-L{line}` URL 복사 + 해당 줄 강조. 앵커로 진입 시 스크롤 + 강조 | P1 |

### 3.2 긴 코드

- 25줄 초과 블록: 약 25줄 높이로 제한 + 하단 페이드 + `N줄 더 보기` / `줄이기` 버튼 (P0)
- 줄이기 상태는 접기와 별개. 펼친 높이 상태는 기억하지 않음

### 3.3 하이라이트

- highlight.js. 언어 지정 블록은 해당 언어
- 언어 미지정: 후보 언어(bash, sql, java, xml, json)로 자동 감지, relevance 12 미만이면 plaintext (M2 실데이터 697블록으로 조정: yaml·ini·python 등은 셸 출력·주석 오탐이 많아 후보에서 제외. 결과 bash 63, sql 26, json 6, java 3, xml 1, plaintext 598)
- 하이라이트는 뷰포트 진입 시 수행. 2,000줄 초과 블록은 하이라이트 없이 plaintext + 줄 번호 (성능 목표 유지)

## 4. 코드 접기 (접은 상태 유지)

### 4.1 동작

- 접힘 상태: 헤더 바 + 첫 줄 미리보기 1줄만 표시
- 상태 결정 우선순위: 사용자 조작 기록 > 문서 기본값(`collapsed`) > 펼침
- 문서 상단 액션: `코드 모두 접기` / `코드 모두 펼치기` (조작 기록에 반영) (P0)
- 자동 펼침: 줄 앵커 진입, 검색 결과에서 진입 시 일치 위치가 접힌 블록 안이면 펼침 (P1)
- 브라우저 찾기(Ctrl+F): 접힌 내용은 `hidden="until-found"` 적용, 일치 시 자동 펼침 (지원 브라우저 한정, P1)
- 인쇄 시 접힌 블록도 펼쳐서 출력

### 4.2 상태 저장

| 범위 | 저장 위치 | 키 |
|------|----------|-----|
| 모든 사용자 공통 기본값 | 문서 본문 (`collapsed` 속성) | - |
| 사용자별 조작 기록 | localStorage | `pb.fold.{pageId}.{blockKey}` |

- `blockKey`: `title`이 있으면 title(같은 title 중복 시 순번 부여), 없으면 `cyrb53(언어 + 코드)` 16진 12자 (http 비보안 컨텍스트에서는 `crypto.subtle`을 쓸 수 없어 동기 해시 사용)
- 코드 내용이 바뀐 블록은 키가 달라져 문서 기본값으로 돌아감 (의도된 동작)
- 최대 1,000개 항목, 오래된 순으로 삭제
- 기기 간 동기화(서버 저장)는 백로그 P2

### 4.3 기본 접힘 저장 (편집 권한자, P1)

- `⋮` → `기본 접힘으로 저장` / `기본 접힘 해제`
- 서버에서 해당 블록 info string의 `collapsed` 토큰만 추가/제거 → 새 리비전 (`summary="코드블록 기본 접힘 변경"`)
- 요청에 `version` 포함 (낙관적 잠금)

## 5. 문서 원문 보기

- `⋮` 문서 메뉴 → `원문 보기` → `/source/{path}`: 읽기 전용 CodeMirror (마크다운 하이라이트, 줄 번호, 검색) (P1)
- 원시 텍스트: `/w/{path}.md` ([F3](F3-tree-links.md) 2절)

## 6. 에디터 지원

| 기능 | 사양 | 우선순위 |
|------|------|---------|
| 미리보기 | 문서 화면과 동일한 코드블록 렌더 | P0 |
| 코드블록 삽입 대화상자 | 툴바 `코드블록` → 언어(자동완성), title, 기본 접힘 체크 → 펜스 삽입 | P1 |
| 에디터 내 코드 하이라이트 | CodeMirror markdown 모드의 코드 언어 하이라이트 | P1 |

| 메서드 | 경로 | 설명 |

## 8. 완료 기준

| 항목 | 기준 |
|------|------|
| 상태 유지 | 블록 접기 → 새로고침 → 접힌 상태 유지 |
| 문서 기본값 | `collapsed` 블록이 첫 진입 시 접힘, 펼친 뒤 새로고침하면 펼침 유지 |
| 모두 접기 | 문서 내 전 코드블록 접힘, 새로고침 후 유지 |
| 복사 | 클립보드에 줄 번호 미포함 |
| 긴 코드 | 26줄 이상 블록에 `N줄 더 보기` 표시 |
| 성능 | 3,768줄 블록 포함 문서(`nems/hw/dell_r760`) 렌더 1초 이내 |
| 이전 데이터 | `<details>` 26건이 `collapsed` 코드블록으로 렌더 |
