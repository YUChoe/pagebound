# M4. 트리 편집, 태그, 검색

- 선행: M3
- 예상: 4일 (F11 검색 확장으로 +1일)
- 범위:
  - [F3](../features/F3-tree-links.md) 4절(이동/이름 변경), 5절(DnD, 컨텍스트 메뉴), 6절(휴지통)
  - [F4](../features/F4-tags.md) 전체 (분류 바 표시는 M2 완료)
  - [F11](../features/F11-search.md) P0 (검색창·자동완성·바로가기, 질의 문법 P0, 결과 화면·패싯, 순위, 한국어 짧은 검색어)

## 작업

| # | 작업 | 검증 |
|---|------|------|
| 1 | 이동/이름 변경 서비스: 순환 검사, 하위 트리 path 갱신, alias 등록, 역링크 본문 치환, 리비전 | 이동 후 참조 문서 링크 치환 |
| 2 | 트리 DnD (순서, 부모 변경), 컨텍스트 메뉴, 이동 대화상자 | 시각 확인 |
| 3 | 휴지통: 삭제(하위 포함 확인, `pages.deleted_by` 기록), 관리자 휴지통 API(목록·복원·영구 삭제, [F12](../features/F12-admin.md) 6절), 30일 영구 삭제 스케줄러(첨부 파일 포함), 감사 로그 테이블과 휴지통 작업 기록 | 영구 삭제 후 첨부 디렉토리 0 |
| 4 | 태그: 자동완성 API, `/tags`, `/tags/{a}+{b}`, 관리자 이름 변경/병합/삭제 | [F4](../features/F4-tags.md) 4절 |
| 5 | 검색 서비스(질의 파서, FTS trigram + 2자 이하 LIKE, 순위, 스니펫, 패싯) + `/api/v1/search`, `/search/suggest` | [F11](../features/F11-search.md) 12절 |
| 6 | 헤더 검색창(`/` 단축키, 자동완성, 바로가기) + 결과 화면 | 시각 확인, 제목 입력 시 바로가기 |
| 7 | 성능 측정 (실데이터 + 합성 2,000문서) | [F11](../features/F11-search.md) 11절 |

## 완료 기준

1. [F3](../features/F3-tree-links.md) 8절, [F4](../features/F4-tags.md) 4절, [F11](../features/F11-search.md) 12절 통과
2. 이동 전 URL 301 → 새 경로
