# M4. 트리 편집, 태그, 검색

- 선행: M3
- 예상: 3일
- 범위:
  - [F3](../features/F3-tree-links.md) 4절(이동/이름 변경), 5절(DnD, 컨텍스트 메뉴), 6절(휴지통)
  - [F4](../features/F4-tags.md) 전체 (분류 바 표시는 M2 완료)
  - [F7](../features/F7-common.md) 1절 (검색)

## 작업

| # | 작업 | 검증 |
|---|------|------|
| 1 | 이동/이름 변경 서비스: 순환 검사, 하위 트리 path 갱신, alias 등록, 역링크 본문 치환, 리비전 | 이동 후 참조 문서 링크 치환 |
| 2 | 트리 DnD (순서, 부모 변경), 컨텍스트 메뉴, 이동 대화상자 | 시각 확인 |
| 3 | 휴지통: 삭제(하위 포함 확인), 관리자 목록/복원, 30일 영구 삭제 스케줄러(첨부 파일 포함) | 영구 삭제 후 첨부 디렉토리 0 |
| 4 | 태그: 자동완성 API, `/tags`, `/tags/{a}+{b}`, 관리자 이름 변경/병합/삭제 | [F4](../features/F4-tags.md) 4절 |
| 5 | 검색 API(FTS trigram + 2자 이하 LIKE, 태그 필터) + 검색 결과 화면 | `통계`, `파티션` 결과 반환 |

1. [F3](../features/F3-tree-links.md) 8절, [F4](../features/F4-tags.md) 4절, [F7](../features/F7-common.md) 6절 중 검색 항목 통과
2. 이동 전 URL 301 → 새 경로
