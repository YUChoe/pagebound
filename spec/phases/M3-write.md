# M3. 에디터, 첨부

- 선행: M2
- 예상: 3일
- 범위:
  - [F1](../features/F1-editor.md) 1절, 2절 P0, 3~4절
  - [F2](../features/F2-attachments.md) 전체
  - [F3](../features/F3-tree-links.md) 레드 링크 클릭 → 새 문서 작성

## 작업

| # | 작업 | 검증 |
|---|------|------|
| 1 | 문서 생성/수정 API: 낙관적 잠금, 리비전(`source='web'`), `page_links` 재계산, 태그 교체 | 동시 저장 시 409 |
| 2 | 섹션 편집: 섹션 원문 조회, 저장 시 병합 | 섹션 외 원문 불변 |
| 3 | 첨부 API: 업로드(파일명 충돌 접미사), 목록(본문 참조 여부), 이름 변경(본문 치환), 삭제, 복사 | API 테스트 |
| 4 | 에디터 화면: CodeMirror 6, 미리보기(M2 렌더러 재사용), 툴바, 단축키, `[[` 자동완성, 태그 칩 입력 | 시각 확인 |
| 5 | 붙여넣기 P0: 스크린샷, 파일 복사, 다중 드래그 앤 드롭, 플레이스홀더 | [F1](../features/F1-editor.md) 5절 |
| 6 | 첨부 패널 (에디터 사이드, 문서 하단), 미참조 배지, 저장 시 검증 경고 | [F2](../features/F2-attachments.md) 6절 |
| 7 | 로컬 임시저장, 초안 선생성(`is_draft`) + 24시간 방치 초안 정리 스케줄러 | 신규 문서에서 붙여넣기 성공 |
| 8 | 레드 링크 클릭 → 해당 경로 새 문서 작성 | 저장 후 원 문서 링크 파란색 |

## 완료 기준

1. E2E: 스크린샷 Ctrl+V → 업로드 → 본문 삽입 → 저장 → 문서 화면 표시
2. [F1](../features/F1-editor.md) 5절, [F2](../features/F2-attachments.md) 6절 완료 기준 전부 통과

## 미포함

- 붙여넣기 P1 (TSV, HTML, URL) → M7
